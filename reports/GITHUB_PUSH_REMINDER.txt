GitHub branch handoff

The project targets https://github.com/Hamza5448/neuromap-ai. Its local
feature/finalize-neuromap-project branch is based on the remote main branch.
Push this branch and merge it into main through the repository's normal review
process.

The local repository is rooted in the NeuroMap project folder. Never push the
parent C:\Users\Lab repository. Dataset files, virtual environments,
checkpoints, split manifests, and generated reports are excluded by .gitignore.
The split manifest contains machine-specific E:\NeuroMap paths and must be
recreated on each machine.
